# HERO × SHOKUN — Game Lab

Two mobile-friendly browser games built with HTML, CSS and JavaScript.

- **Sky Sling**: drag backwards to aim, release to jump, climb platforms and avoid spikes. Includes auto-scrolling, fading platforms, spring platforms and local high scores.
- **Robot Mission**: five robot programming puzzles with movement, repeat and sensor conditions.

## Run locally

```sh
python -m http.server 5173 --directory dist
```

Open http://localhost:5173. For static hosting, publish the `dist` directory.
